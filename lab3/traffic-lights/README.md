# Лабораторна робота 3 — світлофор

## Запуск

```sh
npm install
npm run dev
```

## Модель і поведінка

Послідовність фаз зберігається в `src/components/constants.js`:

```text
red → yellow → green → yellow → red
```

Єдине джерело поточної фази — `phaseIndex` у `TrafficLights.jsx`; видимий колір
обчислюється як `PHASES[phaseIndex]`. Ручний вибір жовтого встановлює індекс `1`.
Під час автоматичного режиму ручні сигнали вимкнені. Лічильники змінюються
тільки від ручного вибору, а перемикання орієнтації не скидає стан.

## Життєвий цикл таймера

Ефект у `TrafficLights.jsx` має залежність `[isAutomatic]`, оскільки це єдине
реактивне значення, яке він читає. Коли режим вимкнений, інтервал не створюється.
Коли режим увімкнений, налаштування створює один `setInterval`, а його callback
функціонально оновлює індекс фази. Така форма оновлення не читає `phaseIndex`
із замикання й не перезапускає інтервал після кожної фази.

Ідентифікатор `intervalId`, повернений `setInterval`, належить цьому ефекту;
функція очищення передає саме його в `clearInterval`. React виконує очищення
перед повторним запуском ефекту при зміні `isAutomatic` та при демонтуванні
компонента. Це також робить коректним додатковий цикл
«налаштування → очищення → налаштування» у Strict Mode.
